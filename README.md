# Human Wonder — "Talk to the infinite sky" (Android POC, v2)

A chatbot whose small language model runs **entirely on the phone**. The model ships inside the
APK, so there is no download step, no network permission, and nothing the user types ever leaves
the device. In the app the AI is **Orbit 412**, the voice of the Human Wonder satellite; the
underlying model is never named to users.

v2 is rebuilt on the architecture of [OfflineLLM](https://github.com/jegly/OfflineLLM) by jegly
(Apache-2.0): Hilt, Room conversation history, Navigation Compose, its settings storage and its
`smollm` llama.cpp module. Human Wonder's persona, design, model and build sit on top; OfflineLLM's
UI is replaced entirely. See `NOTICE` and `third_party_licenses/`.

## The experience

1. **Landing** – the lone wanderer on the Liwa dunes, "The sky has something to tell you."
2. **Name** – a long-exposure star-trail sky, "What should Orbit 412 call you?" (first run only).
3. **Home** – aurora sky, "Good evening, {name}", the Orbit 412 card with its live status and
   "Talk to Orbit 412", the last three transmissions, and questions to ask tonight.
4. **Side menu** (menu button on Home and in the chat) – search, new conversation, conversations
   grouped Today / Yesterday / Earlier with rename and delete, and the profile row.
5. **Chat** – the Gemini-style conversation from v1: aurora that sinks once you talk, answers that
   fade in, Orbit / Ground and Balanced / Poetic / Scientific / Whisper, voice typing, copy.
6. **Profile & settings** – name, email, home sky, default view and tone, read answers aloud,
   haptics, export and clear transmissions, about and licenses. Everything stays on the phone.

The design source is the preview canvas in `design/preview/` (Home, Drawer and Profile are
generated by `design/preview/gen/hub.py`; the Compose code uses the same values).

## Build (Mac, no Android Studio needed)

Double-click **`Build Human Wonder.command`** (or run `bash tools/build-on-mac.sh`). The script
installs Java 21 + the Android SDK (platform 37, NDK 29.0.14206865, CMake 3.31.6) into
`~/human-wonder-android-tools` (you accept Google's SDK licenses), fetches the pinned llama.cpp
source if the folder doesn't have it, downloads the model once into `app/build/hw-model/`
(SHA-256 verified), builds `HumanWonder-POC.apk` (~500 MB) and installs it on a USB-connected
phone. The first v2 build takes about 15-30 minutes (new Gradle 9 toolchain + llama.cpp).

Or: `git clone --recursive …` and `./gradlew :app:assembleRelease` with JDK 21 and an Android SDK
that has platform 37, NDK 29.0.14206865 and CMake 3.31.6.

Toolchain (OfflineLLM's, as its CI builds it): Gradle 9.8.2, AGP 9.5.1 with built-in Kotlin,
Kotlin 2.4.21, KSP 2.3.13, Hilt 2.60.1, Room 2.8.5, Navigation 2.10.2, Compose BOM 2026.09.00.
compileSdk 37, minSdk 33 (Android 13), targetSdk 36. The native build is CPU only (no Vulkan, so
no shader compiler or host C/C++ compiler is needed).

## How it works

```
app/     ai.humanwonder.poc
  MainActivity, HumanWonderApplication (Hilt)   AppViewModel (profile, sky, side menu, settings)
  ChatViewModel (one chat), ChatState (Perspective, Tone, SkyState, ChatMessage, UiState)
  ai/    InferenceEngine (SmolLM wrapper)  ModelManager (bundled model, wake, prepareChat)
         Persona (Orbit 412 system prompt, hints + /no_think, visibleAnswer, lostSignalMessage)
  data/  Room: Conversation, Message, DAOs, ChatDatabase   ChatRepository (+ JSON export)
         SettingsRepository (encrypted prefs: the profile)
  di/    AppModule, DatabaseModule, InferenceModule
  ui/    Theme, Components, Sky, GalaxyBackground (aurora shader), OnboardingScreens, ChatScreen,
         HomeScreen, ConversationDrawer (side menu), ProfileScreen, LicensesScreen
  ui/navigation/  Routes, NavGraph
  utils/ TtsHelper, FileUtils, SecurityUtils
smollm/  ai.humanwonder.poc.smollm: SmolLM + GGUFReader (Kotlin), JNI glue (C++) ── llama.cpp
third_party/llama.cpp   submodule pinned to 620d222 (OfflineLLM's pin; also in llama.cpp.commit)
```

- First launch: `ModelManager` copies `assets/hw-core.gguf` out of the APK (status "Orbit 412 is
  rising over the horizon, n%"), loads it ("finding your signal…"), then "overhead now". A phone
  that ran v1 already has the copy and skips that step.
- Each chat replays its newest turns into a fresh context (`prepareChat`); later questions reuse
  the KV cache. Context window 2,048 tokens. A new name or home sky rebuilds the persona on the
  next question.
- Model file and checksum are pinned in `app/build.gradle.kts` (`fetchModel` task); it is not
  committed to git. `HW_MODEL_FILE=/path/model.gguf` builds with a local file instead.

## Notes

- Answers come from a very small model: charming, but it can be wrong about facts.
- Anyone who unpacks the APK can still identify the model file from its metadata; the app just
  never says it. Keep this repository **private** if that matters.
- Signed with a committed POC key (`keystore/`) so builds install over each other (and over v1);
  use the `HW_KEYSTORE*` environment variables to sign with a private key for real distribution.
- Licences: OfflineLLM (Apache-2.0, `third_party_licenses/`), llama.cpp (MIT), fonts (OFL), model
  and icons (Apache-2.0); the texts are bundled in the APK under `assets/licenses/` and shown in
  Profile & settings → Open-source licenses.
